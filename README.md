# Bluegrass Lawn & Landscape — Portfolio Demo

A fictional landscaping business website. No landscaping services are offered.

## Publish on GitHub Pages
1. Create a public GitHub repository (e.g. `bluegrass-landscape`).
2. Upload `index.html` to the repository root.
3. Under Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io/bluegrass-landscape/` after deployment.

## Before using for a real business
- Replace the fictional company name and sample service descriptions with approved business details.
- Replace external illustrative Unsplash images with appropriately licensed real project photos.
- Connect a secure form submission provider and publish an appropriate privacy notice.
- Verify hosting terms, accessibility, SEO, and contact details.

The demo quote form intentionally does not send or save data. Images and Google Fonts require internet access.
